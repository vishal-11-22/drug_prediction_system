# 📌 Project Overview

Drug Prediction System is an AI-powered healthcare application developed to predict suitable medicines based on medical-related inputs using Machine Learning algorithms.

The project focuses on analyzing healthcare data, identifying patterns, and generating intelligent predictions that can assist in healthcare decision-making.

This project reflects my interest in Artificial Intelligence, healthcare technology, and building real-world applications using Machine Learning.

---

# 🚀 Features

✅ Drug prediction using Machine Learning  
✅ Healthcare data analysis and preprocessing  
✅ Intelligent recommendation system  
✅ User-friendly web interface  
✅ Fast and responsive predictions  
✅ End-to-end ML workflow implementation  
✅ Real-world healthcare use case  

---

# 🧠 How It Works

1. User enters healthcare-related information.
2. The system preprocesses the input data.
3. Machine Learning models analyze the patterns.
4. The application predicts suitable drug recommendations.
5. Results are displayed through a simple interface.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/vishal-11-22/drug_prediction_system.git
```

## 2️⃣ Navigate to Project Directory

```bash
cd drug_prediction_system
```

## 3️⃣ Create Virtual Environment (Optional)

```bash
python -m venv venv
```

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

## 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 6️⃣ Run the Application

```bash
python app.py
```

## 7️⃣ Open in Browser

```text
http://127.0.0.1:5000/
```
